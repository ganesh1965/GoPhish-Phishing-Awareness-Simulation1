# GoPhish Phishing Awareness Simulation

A localhost-only phishing simulation lab built using **GoPhish, MailHog and Python** to understand phishing attacks, monitor user interactions and improve cybersecurity awareness.

## 📸 Project Preview

The following screenshot shows the results of our simulated phishing campaign.

![GoPhish Campaign Dashboard](05-Results-and-Analysis/screenshots/12-campaign-dashboard.png)

## 🎯 Project Objectives

- Understand phishing attacks and social engineering techniques.
- Build a controlled phishing simulation environment.
- Monitor email opens, link clicks and form submissions.
- Analyze campaign results and identify security awareness gaps.
- Promote safe email practices and phishing awareness.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| GoPhish | Phishing campaign management |
| MailHog | Local email testing |
| Python 3 | Landing-page application |
| Git & GitHub | Version control and documentation |

## 🌍 Real-World Importance

This project demonstrates how organizations can identify phishing awareness gaps, educate employees, encourage suspicious-email reporting and reduce the risk of credential compromise.

These principles can support authorized security-awareness programs in educational institutions, banks, hospitals and IT organizations.

## 📊 Initial Campaign Findings

Our MICROSOFTFAKE simulation recorded:

- Emails sent: 1
- Emails opened: 1
- Links clicked: 1
- Forms submitted: 1

The results indicate a potential security-awareness gap in the simulated scenario.

## ⚠️ Ethical Disclaimer

This project is intended for educational purposes and authorized security-awareness testing only. The lab uses localhost (`127.0.0.1`) and synthetic identities. No real users, external inboxes, passwords or OTPs should be targeted or collected.

**Learn phishing. Identify risks. Improve security awareness.**
